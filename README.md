# Tanisha Panda — personal site

Personal portfolio from the Website brief: About, Work Experience, Projects, Felicitations, and Connect.

**Live:** enable GitHub Pages on this repo (`main` / root), then open `https://tanisha-io.github.io/portfolio/`.

Projects link out to PDFs and code on [trex.io](https://github.com/Tanisha-io/trex.io).

Contact form uses [FormSubmit](https://formsubmit.co/) to `kaitanisha2601@gmail.com` (confirm the email once on first submit). You can swap the form `action` for Google Forms or Getform/Forminit later.

## Local

Open `index.html`, or:

```bash
python -m http.server 8080
```
